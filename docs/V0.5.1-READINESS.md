# TOVARIX v0.5.1 · PIXELFORGE UZ

## IMPLEMENTED AND VERIFIED

- Псевдоним CONTROL сопоставляется с подтверждённым UID на сервере. Публичный клиент получает общее сообщение об ошибке. Вход использует Supabase Auth, лимит составляет восемь попыток на псевдоним за пятиминутное окно. Успешная проверка пароля фиксируется в платформенном аудите. Локальный интеграционный тест прошёл реальную проверку пароля и TOTP в GoTrue, отказ на AAL1, доступ на AAL2 и глобальный выход. Тест использовал синтетический аккаунт.
- TOVARIX AI сохраняет отдельные диалоги и сообщения, поддерживает поиск по заголовку, переименование, удаление, быстрые команды, Markdown, таблицы, график выручки и остановку потока. Доступна загрузка JPEG, PNG, WebP и PDF до 1,4 МБ. История ответов с защищённой финансовой информацией закрывается при отзыве права на прибыль. Сводки по продажам, расходам, остаткам и долгам приходят из серверных функций в пределах полномочий.
- Выполнен реальный синтетический облачный пилот Gemini. HTTP 200, три пакета выдачи, модель `gemini-3.1-flash-lite`, история сохранена, зафиксировано 319 входящих и 27 исходящих токенов. Повтор после исчерпания пилота получил 503, запрос без токена получил 401. Временный аккаунт удалён. Глобальный AI выключен. CORS подтвердил 204 для клиентского сайта, существующего Preview, Android и CONTROL, 403 для чужого origin.
- Подтверждаемое изменение цены реализовано с проверкой предприятия, исполнителя, полномочий, тарифа, старой цены, срока действия в 15 минут и аудитом. Тесты подтвердили отмену, отказ после истечения срока, отказ при изменившейся цене и одну запись аудита при повторном подтверждении.
- SUPER_ADMIN с AAL2 может управлять пилотом, выключать и включать глобальный AI, менять дневной лимит запросов и денежный резерв, выполнять аварийную остановку. Статистика токенов сохраняется при удалении диалога. Резерв рассчитывается до генерации по входящим токенам и верхней границе ответа. Лимиты тарифов сохранены, суточный расчёт использует Asia/Tashkent. Ставки Gemini 3.1 Flash-Lite Standard составляют $0,25 за миллион входящих токенов для текста/изображений и $1,50 за миллион исходящих токенов, включая thinking. Биллинг не менялся. [Тарифы Gemini API](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite).
- Supabase получил миграции `20261127150000_control_alias.sql`, `20261127150100_ai_conversations.sql`, `20261127150200_ai_price_actions.sql`, `20261127150300_ai_budget_control.sql` и `20261127150400_ai_rpc_boundaries.sql`. Повторного применения 31 исходной миграции не было. Развёрнуты `control-login` и обновлённый `tovarix-ai`. Автоматическое проведение платежей выключено.
- Пройдены TypeScript, ESLint, Deno check, 12 автоматизированных тестов, PostgreSQL 17, Chromium E2E, Firefox `file://` E2E, npm audit. Chromium проверил UI чата с воспроизводимым тестовым SSE и реальным локальным хранилищем диалогов. Реальная потоковая выдача проверена отдельно в облаке. Обе темы и три языка проверены в standalone. Собраны Web/PWA, CONTROL, HTML и Android debug APK. Подпись debug APK проверена.
- Артефакты ветки доступны в [GitHub Actions](https://github.com/asadbek20100roblox-sudo/tovarix/actions/workflows/build.yml?query=branch%3Acodex%2Ftovarix-commerce). Изменения в [PR #1](https://github.com/asadbek20100roblox-sudo/tovarix/pull/1). Публичная версия сайта не переключалась.

## BLOCKED

- У указанного владельца в Supabase отсутствует подтверждённый UID. `ADMIN63` ещё не привязан, облачных SUPER_ADMIN нет. Пароль задаёт владелец через Supabase Auth. Подтверждение адреса, привязка UID и TOTP описаны в [точке продолжения](NEXT-STEPS.md).
- Бинарный официальный PNG не обнаружен. Требуется оригинал в `public/brand/tovarix-original.png`. Новые иконки, splash и интеграция фирменного изображения ждут исходник.
- Предупреждение о защите от скомпрометированных паролей остаётся открытым. [Supabase Auth](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection).
- Обработка реальных персональных и торговых данных ждёт юридического согласования и настройки рабочего SMTP.
