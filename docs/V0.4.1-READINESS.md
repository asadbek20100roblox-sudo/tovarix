# TOVARIX v0.4.1 · PIXELFORGE UZ

Ветка `codex/tovarix-commerce`, черновой [PR №1](https://github.com/asadbek20100roblox-sudo/tovarix/pull/1). Производственный [короткий адрес](https://tovarix-uz.vercel.app/) оставлен на v0.3.0. Сборка для проверки использует отдельные защищённые Preview. Используйте синтетические данные до юридической проверки региона Mumbai.

## IMPLEMENTED AND VERIFIED

- **RBAC.** У `authenticated` отозван прямой SELECT себестоимости, сумм закупок, себестоимости возвратов и сырого JSON чеков. API использует `catalog_access`, `sales_access` и `purchase_access`. Старые чеки и частичные возвраты сохранены. Публичный JSON чека содержит цену продажи и признак возможности возврата без `unit_cost`. Суммы себестоимости и агрегированная прибыль разграничены правами `cost` и `profit`. AI-контекст маскирует прибыль при отсутствии соответствующего права. SQL-тест проверяет сырые поля, собственный чек кассира, права после явного назначения и чужое предприятие.
- **Кэш и офлайн.** Кэш v0.4.1 хранит безопасную проекцию, включая миграцию прежнего кэша при первом открытии филиала. Мобильный E2E прошёл создание предприятия, кассу, восстановление очереди и конфликт остатка. Данные сервера остаются источником проведения продажи.
- **Auth.** Добавлены повторная отправка подтверждения, сообщение об истёкшей ссылке, задержка повторной попытки в UI и обработка ошибок отправки. Удалённый Auth публично сообщает email enabled, email autoconfirm false и phone disabled. Локальный GoTrue подтвердил синтетический email настоящим signup token, установил recovery-сессию, сменил пароль и вернул `otp_expired` для состаренной тестовой ссылки.
- **Gemini.** Существующая Edge Function обновлена до версии 2. Выполнено одно успешное реальное обращение с временным синтетическим аккаунтом и лимитом пилота в один запрос. HTTP 200, модель `gemini-3.1-flash-lite`, ответ непустой. Повтор после исчерпания пилота получил 503. Удалённые отрицательные проверки: без токена 401, поддельный токен 401, чужой origin 403, чужое предприятие 403, сотрудник без права AI 403, исчерпанная дневная квота 429. Правильно подписанный просроченный JWT получил 401 в локальном стенде GoTrue/Edge. Временные записи тестов удалены, общий переключатель AI остался выключен.
- **CONTROL.** Локальный TOTP challenge выдал AAL2 синтетическому пользователю. При AAL2 без platform admin данные CONTROL всё равно недоступны. Существующий SQL-тест проверяет отказ назначенному админу при AAL1. Короткий адрес требует вход Vercel, а с доступом команды возвращает HTTP 200. Обход защиты для этого алиаса не создавался.
- **Схема.** Сопоставлены 27 ранее применённых миграций. На выделённый проект применены только `20261127115130_cost_isolation.sql` и `20261127115340_ai_isolated_pilot.sql`. Security Advisors показал 15 информационных находок RLS без policy в закрытой схеме `commerce_private`. Отдельной проверкой direct table grants обнаружено 0 таблиц этой схемы, доступных ролям `anon` или `authenticated` для чтения и изменений.
- **QA.** TypeScript, ESLint, Deno check, 6 unit/SQL-тестов, PostgreSQL integration, npm audit (0 известных уязвимостей), мобильный браузерный E2E, standalone через file://, Web/PWA, CONTROL и Android debug прошли. Проверены 320, 390, 768 и 1440 px в обеих темах на демо и закрытом CONTROL. Проверены подпись APK, package version `0.4.1`, versionCode `5` и наличие прежнего adaptive launcher resource в APK. [GitHub Actions](https://github.com/asadbek20100roblox-sudo/tovarix/actions/runs/45994883519)

## BLOCKED

- Оригинальный файл логотипа отсутствует. Загрузите исходный PNG в `/workspace/tovarix/public/brand/tovarix-original.png` или передайте его как скачиваемое файловое вложение. Фирменные производные, splash и системные иконки из оригинала не создавались.
- Для теста облачной почты откройте проект TOVARIX → Authentication → URL Configuration. Задайте тестовый Site URL и точный redirect URL защищённого клиентского Preview: `https://tovarix-preview-hyikxbavp-pixel-forge-d3e8.vercel.app/`. В Authentication → SMTP Settings проверьте отправителя и действующее SMTP, а в Rate Limits — доступные ограничения. Используйте подтверждённый тестовый ящик, которым владеет команда. Затем проверьте регистрацию, resend и восстановление. Не отключайте email confirmation.
- Для первого CONTROL admin нужен User UID подтверждённого аккаунта владельца из Authentication → Users. Назначение выполняется доверенным оператором в закрытой таблице после проверки UID, происхождения записи и подтверждённого email. Первый вход требует пройти настройку TOTP; данные доступны после AAL2.
- Публичная коммерческая регистрация, персональные данные и платёжные провайдеры требуют согласования юридических и провайдерских условий. Облачный Preview защищён, общая публикация не переключалась.

## NOT IMPLEMENTED

- Полностью произвольные роли, приглашения, отзыв Auth-сессий, все раздельные операционные права и полный каталог тарифных функций. Выбор активного набора товаров/филиалов после downgrade остаётся отдельным модулем. Согласованные цены и лимиты не изменены.
- AI pending actions с подтверждением, TTL и идемпотентностью, отдельные чаты, отмена и потоковая передача. Глобальный счётчик запросов реализован ранее; строгого денежного бюджета ещё нет.
- Полный CONTROL, расширенный склад, долги, Wallet, Click/Payme. Тесты Wallet и AI-confirmation не запускались, поскольку эти модули отсутствуют. Реальные платежи не активированы.
