# TOVARIX v0.2.0

## Upgrade

Apply the additive migrations in order to a dedicated TOVARIX database after taking and verifying a backup. The rollout requires the database migrations before the new Web or Android client. Existing catalog and membership records are retained. Older single-sale outboxes are imported into IndexedDB on the next authenticated open.

- A product with unit `kg` accepts three decimal places. Each extended sale price and cost rounds half up to whole UZS. New sale lines carry the operator and the expected price. Server retries retain their existing request identity.
- Partial returns are available for new sales with item cost snapshots. Legacy sales retain full returns. Partial returns are recorded one item at a time, with cumulative discount and tender allocation. Refund payment is still performed outside TOVARIX. Legacy sales cannot supply historical item cost details retrospectively.
- Stocktake compares the recorded quantity with the latest locked stock balance. A change after the count began requires review. Multiple purchase items are received in one transaction. The catalogue cost remains the basis of COGS, with no weighted-average or FIFO ledger.
- Branch access defaults to the previous behavior for existing members. A business owner can restrict the list from the staff page. A reduced or expired plan leaves membership data intact. The effective limit is applied in stable user-ID order. The platform can configure the PREMIUM technical limit in `plan_catalog`; the previous value remains the initial setting.
- Closed shifts save expected, counted and difference amounts. The expected amount uses opening cash, cash sales and confirmed accounting returns. Expenses are branch records and do not act as cash-drawer withdrawals.
- Support tickets are available in each workspace. Open `?mode=platform` for the PixelForge panel. A trusted database operator grants access by inserting a verified Auth user ID into `commerce_private.platform_admins`. The panel provides counts, open tickets, ticket resolution and administrative resolution history. It does not provide customer administration, error telemetry or payment management.
- AI history is isolated by business and account and stored without uploaded images. Successful responses may include model token counts and estimated cost after rates are entered in `commerce_private.ai_model_rates`. Configure daily quotas in `commerce_private.ai_plan_limits`. The existing trial-feature and plan entitlement tables still control AI availability. Model responses and prior chat are never executed as instructions. A business-restricted employee cannot load the business-wide AI context. Gemini requires a real server key and provider testing.
- IndexedDB retains pending requests and the last 50 confirmations for each account, business and branch. Open the matching branch while signed in to synchronize. Transport failures are retried automatically in the foreground. Database conflicts are retained for review, and are not submitted again automatically. Previously submitted transactions cannot be moved to a different account. Sales pending on another device are still subject to server stock validation.
- Hardware diagnostics tests input from the camera decoder and keyboard-emulating scanners. The diagnostic print action uses the browser print UI. Physical ESC/POS, scales and cash drawers require a compatible native transport and on-device validation.
- `?mode=demo` uses its own local storage with no Supabase connection. An unconfigured ordinary build retains the separate legacy local workspace. Vercel is configured to build `dist` and deliver security headers. Use only a public Supabase key in the Web configuration and server secrets in Edge Functions.

## Open release gates

Production onboarding, SMTP invites, verified backups, PSP Checkout, fiscal receipts, physical hardware, lot/expiration stock allocation, serial/warranty lifecycles, dynamic costing, proactive stock/subscription notifications and complete platform administration still need work. The demo and debug APK do not connect to production by default.
