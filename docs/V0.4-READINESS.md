# TOVARIX v0.4.0 · readiness

## IMPLEMENTED AND VERIFIED

- Базовый прогон v0.3.0 перед изменениями. Шесть unit/SQL-тестов v0.4.0, включая отдельный сценарий trial и тарифов. Тесты проверяют срок trial, повторную активацию, дедупликацию подтверждённого email, изоляцию, тарифные ограничения, квоты и отказ CONTROL при AAL1.
- Выделенный Supabase `jkjexgcssglzweayztel`, PostgreSQL 17, `ap-south-1`. Исходная публичная схема была пуста. Применены исходная схема и шесть миграций v0.4.0. Публичный Auth settings подтверждает email, отключённое автоподтверждение и выключенный телефонный вход.
- Локальный синтетический браузерный E2E прошёл регистрацию с обязательными полями, подтверждение паролей, создание предприятия, кассу и восстановление очереди офлайн. Тестовая среда использует автоподтверждение, поэтому это не тест доставки email.
- Серверные лимиты товаров, филиалов и сотрудников, эффективный тариф, 30-дневный PREMIUM Trial при первом предприятии с подтверждённым email, сохранение записей после истечения. Платные гейты записи расходов, поставщиков и закупок. Недоступный после истечения филиал блокирует новые продажи и открытие смены. Использованы существующие таблицы и сохранены утверждённые цены.
- Серверная блокировка и разблокировка сотрудников с журналом, роли администратора предприятия и бухгалтера, права через существующий набор разрешений и выбор филиалов.
- CONTROL отдельным Web-артефактом с закрытой проверкой platform admin и JWT AAL2. SQL-тест проверил отказ без второго фактора и доступ при синтетическом AAL2. Первый администратор на удалённом проекте отсутствует.
- Edge Function `tovarix-ai` развёрнута, запрос без сессии получил 401. В коде потоковое ограничение размера запроса, ограниченные серверные данные, поиск поддерживаемой стабильной Flash-Lite при отсутствии явной модели, дневные квоты по Ташкенту, общий дневной потолок количества запросов и аварийный выключатель. На сервере AI выключен.
- Пройдены TypeScript, ESLint, Deno check, npm audit, Web/PWA, отдельный CONTROL, автономный HTML через file:// без сети и сборка Android debug с проверкой подписи. [Артефакты ветки](https://github.com/asadbek20100roblox-sudo/tovarix/actions?query=branch%3Acodex%2Ftovarix-commerce)

## IMPLEMENTED BUT NOT VERIFIED

- Почтовые сценарии доставки подтверждения и восстановления, реальная регистрация в удалённом Auth, лимиты SMTP. В пилоте отображаются пилотные условия, а не утверждённая юридическая оферта.
- Настоящий ответ Gemini, список моделей конкретного ключа и живой TOTP администратора. Секрет остаётся на сервере. Наличие и валидность ключа через успешный вызов не подтверждены.
- Нативные устройства Android и проверка логотипа на launcher/splash. Самостоятельный HTML остаётся локальным демо.

## BLOCKED

- Два логотипа отображаются в сообщении, но бинарные исходники не предоставлены файловой среде. Новые изображения не добавлялись. Для исходников нужен файловый доступ.
- Публичный облачный запуск с персональными данными ожидает юридической проверки региона, условий и хранения данных. Текущий публичный адрес [TOVARIX](https://tovarix-uz.vercel.app/) оставлен на v0.3.0. До проверки используйте синтетические данные.
- Платежи Click, Payme и фискализация требуют договоров, доступов и проверок. Автосписание и реальные платежи не включены.

## NOT IMPLEMENTED

- Индивидуальные роли и недостающие раздельные права (в частности, сокрытие себестоимости), приглашения, полная матрица планов, бизнес-логотипы, ручная проверка повторной активации по сигнальным данным.
- Долги, дополнительная детализация складов/категорий/движений, кошелёк и неизменяемый журнал кошелька.
- AI-предложения с подтверждением, идемпотентными инструментами и TTL, новый чат, потоковая выдача токенов и бюджет денежных расходов. Дневной общий потолок запросов есть.
- Полный CONTROL для клиентов, платежей, управления тарифами, системных ошибок и уведомлений. В текущей панели доступны агрегаты и работа с обращениями.

## Изменения и эксплуатация

- UI: `src/AccountAccess.tsx`, `src/Workspace.tsx`, `src/plans.ts`, `src/control.tsx`, `src/supabase.ts`.
- Миграции: `live_entitlements`, `authenticated_onboarding`, `staff_access_controls`, `control_mfa`, `ai_global_quota`, `paid_feature_gates` в `supabase/migrations/`.
- Edge: `supabase/functions/tovarix-ai/`. Платёжная функция сохраняется в исходниках без активации провайдера.
- Поставка: `control.html`, `vite.control.config.ts`, `.github/workflows/build.yml`, версия Android и npm. [PR №1](https://github.com/asadbek20100roblox-sudo/tovarix/pull/1)
- Security Advisors на целевой базе: информационные находки RLS без политик в закрытой схеме `commerce_private`. Эти таблицы обслуживаются привилегированными серверными функциями. Публичные пользовательские политики от этого результата не считаются доказанно безопасными.
- Владельцу: см. [точку продолжения](NEXT-STEPS.md) с порядком действий и ограничениями миграций.
