# TOVARIX v0.4.1 · точка продолжения

Ветка `codex/tovarix-commerce`, черновой PR №1. Публичный `tovarix-uz.vercel.app` остаётся на v0.3.0. Состояние кода, подтверждённые проверки и ссылки собраны в [V0.4.1-READINESS.md](V0.4.1-READINESS.md).

1. Получить оригинальный PNG в `public/brand/tovarix-original.png`; подготовить производные изображения и проверить Android/PWA safe zones.
2. Проверить SMTP и URL Configuration на выделенном Supabase по шагам отчёта. Получить синтетический тестовый ящик команды и проверить облачную доставку signup, resend и recovery. Автоподтверждение email отключено.
3. Получить UID подтверждённого аккаунта владельца, проверить его и назначить platform admin доверенной серверной операцией. Живой CONTROL требует TOTP и JWT AAL2.
4. Продолжить с отдельными операционными правами, приглашениями, Auth session revocation и выбором активного набора после downgrade. Сокрытие себестоимости уже внедрено через column-level grants и RLS-preserving views. Не возвращать сырые поля в клиентские запросы. Старый облачный Preview v0.4.0 обращается к отозванным колонкам. Для работы с проектом использовать Preview v0.4.1.
5. После проверки хранения персональных данных и условий тестового доступа настроить точный `TOVARIX_ALLOWED_ORIGINS` для утверждённого адреса. Исходный `GEMINI_API_KEY` подтверждён единственным успешным живым запросом, новый ключ не нужен. Глобальный AI выключен. Продолжить реализацию подтверждаемых AI-действий, кошелька, складского учёта и CONTROL.
6. Перед публичным переключением пройти облачный Auth, назначение администратора, проверку SMTP, миграции и регрессию реальных ролей. Платежи и фискализация требуют отдельных договоров и разрешений.

Удалённые версии миграций имеют префикс имени `tovarix_` и локальный номер в имени. Сверять по имени, поскольку timestamp удалённого журнала создаётся сервером. Исходные 27 миграций повторно не применять. Две миграции v0.4.1 уже на проекте `jkjexgcssglzweayztel`.

Для повторной локальной проверки: `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:postgres` с отдельной БД, `npm run test:browser` с локальными GoTrue/PostgREST, `npm run build`, `npm run build:control`, `npm run test:single`, Gradle debug.
