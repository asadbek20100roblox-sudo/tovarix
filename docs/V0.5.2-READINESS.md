# TOVARIX v0.5.2 · PIXELFORGE UZ

## IMPLEMENTED AND VERIFIED

- Публичный клиент обслуживает v0.5.2 с конфигурацией проекта Supabase `jkjexgcssglzweayztel`. Страница `/release.json` ответила HTTP 200 с версией `0.5.2`. Браузер подтвердил облачный экран входа, закрытую регистрацию и отсутствие вызовов Supabase в явном деморежиме. При отсутствии облачной конфигурации основной режим показывает ошибку подключения. [Клиент](https://tovarix-uz.vercel.app/) · [Демо](https://tovarix-uz.vercel.app/?mode=demo) · [Версия](https://tovarix-uz.vercel.app/release.json).
- CONTROL обслуживает v0.5.2. Версия проверена через аутентифицированную проверку Vercel. Неаутентифицированный запрос получил HTTP 302 на Vercel SSO. [CONTROL](https://tovarix-control.vercel.app/).
- Зарегистрироваться можно по доверенному приглашению Auth. Публичная кнопка регистрации скрыта, создание обычного пользователя дополнительно закрыто триггером в Supabase. Метаданные запроса не заменяют признак приглашения. Серверный шлюз `control-login` остался прежним. Локальная проверка GoTrue прошла с действительным TOTP, AAL1 был отклонён, AAL2 получил доступ.
- CONTROL получил 13 разделов, обзоры пользователей и предприятий, поиск и статистику, операции блокировки и отзыва сессий, управление датами подписок и окончанием пробного периода, финансовый список подтверждённых заявок и публикацию объявлений. Изменения проверяют подтверждённый SUPER_ADMIN с JWT AAL2 и пишут аудиторские записи. Административное назначение тарифа не создаёт запись о подтверждённой оплате.
- Промокоды создаются для выбранного тарифа, имеют срок действия, историю применений и управляемую доступность. Скидка включается в сумму ручной заявки до перехода в Telegram. Лимиты двух выпусков в месяц, трёх применений и одного применения на аккаунт проверяются сервером. Ручная активация сохраняет проверку платежа. Click, Payme и автосписание остаются отключены.
- Реальный синтетический пилот Gemini вернул HTTP 200, три фрагмента потока, 319 входящих и 31 выходной токен. Модель `gemini-3.1-flash-lite`. Ответ сохранился в истории. Повтор сверх квоты получил 503, запрос без токена получил 401. Синтетическое предприятие и пользователь удалены, глобальный AI оставлен выключенным.
- Новые миграции `20261127160000_invite_only_registration.sql`, `20261127160100_control_directory.sql`, `20261127160200_manual_promo_control.sql` применены в заданном проекте. Предыдущие 36 миграций не повторялись.
- TypeScript, ESLint, Deno check, 15 unit/SQL-тестов, отдельный PostgreSQL 17, Chromium E2E, Firefox offline E2E и npm audit прошли. Собраны Web/PWA, CONTROL, автономный HTML и подписанный отладочным ключом Android APK. [GitHub Actions](https://github.com/asadbek20100roblox-sudo/tovarix/actions/runs/46035509726) · [HTML без ZIP](https://tovarix-uz.vercel.app/downloads/TOVARIX.html).
